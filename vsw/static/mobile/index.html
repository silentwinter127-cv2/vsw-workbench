连接电脑上的工作台

手机本身跑不了无头浏览器，所以「自动识图」只能在电脑上执行。 这里填电脑的局域网地址，就能同步一份快照到手机上离线看、也能把手机拍的照片推回电脑。

用电脑屏幕上的二维码对准手机扫；也可以把地址直接填在上面
怎么让别人也能用

这个应用本身只是一个"看板"，它需要连到一台跑着视觉搜索工作台的电脑 （那台电脑负责搜索、去重、排序——手机做不了无头浏览器）。给别人用的时候：

  1. 把 vsw 文件夹和工作台源码给对方
  2. 对方电脑上装 Python，然后跑 start_vsw_lan.bat
  3. 对方在这个应用里填自己电脑的地址（或扫启动日志里的二维码）

不想让对方装 Python 也行：你在自己电脑上导出一份数据集文件发给他， 他在下面「导入数据集」即可离线浏览（能看结果、来源、回放链，但不能搜新图）。

同步快照
离线收件箱

手机上拍/选的图、框选结果、以及离线时删掉的对象都会先存在这里， 回到同一 WiFi 后一键推回电脑。数据集也可以导出成文件，用数据线拷给别人。

安装到桌面

浏览器菜单里选「添加到主屏幕」即可当 App 用（iOS 用 Safari 的分享 → 添加到主屏幕）。 装好后即使连不上电脑也能打开看本地库。

service worker 存储

视觉搜索工作台 · 手机版

「搜索引擎负责发现，工作台负责调度、去重、排序和积累知识。」 手机端负责随时翻看与收集；真正的批量搜索、三层去重、发散度排序在家里那台电脑上跑。

1连上你（或对方）电脑上的工作台

推荐这个。电脑负责搜索与去重，手机只当看板 —— 所有能力都完整。

  1. 电脑上装 Python 3.10+，进入工作台目录
  2. 双击 start_vsw_lan.bat（等于 python -m vsw.server --host 0.0.0.0 --port 8799）
  3. 启动日志里会出现一个二维码和几个地址，扫它或手填到下面

电脑和手机要在同一个 WiFi 下。 工作台目前没有口令，别在公共 WiFi 上开放。

2导入一份数据集，先离线看看

别人给你导出过一个 .json 数据集可以直接选它。 能离线浏览结果板、来源页、搜索链回放，也能做归档与清理；但搜新图需要电脑。
