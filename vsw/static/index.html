入库归档

归档**不是删除**：它给这批结果留一份快照（对象数、来源数、平台数、队列分布、时间跨度、体积）， 然后把它们从活动结果板上收起来，让结果板重新变短、指标只反映"正在查的"这一轮。 归档的图片和来源都还在磁盘上，随时可以整体恢复；引擎下次检索也不会把它们当成重复基准。
★ **只归档选中的图片**：先到「结果板」勾选卡片（「选为种子」就是勾选），再回来点这里 —— 选了几个就只归档几个，其余留在板上继续查。

衡量成功的指标

不看搜索次数，看「每 100 次搜索操作换来多少真正扩网的东西」。操作 = 一次派发到引擎的检索。

探索价值公式

权重合计
E(i) = wN·Ni + wP·Pi + wB·Bi + wM·Mi

N 新颖性（与已有结果差异）· P 来源潜力（能否找到可追溯原始页）· B 桥接价值（能否连到未探索的簇/平台）· M 元数据价值（日期、站点、尺寸等线索）。各指标归一化到 0–1。

权重只是初始假设，应按下你自己筛出的高价值结果调整，而不是找通用最优值。

三层去重与分队列阈值

文件层 SHA-256 → 视觉副本层 pHash（汉明距离）→ 语义层 SigLIP 余弦。三层都过不了才算是「新的一张图」。
